# Accessibility

Accessibility information for James Tripp’s website.

I want this website to be usable by as many people as possible. I aim to meet WCAG 2.2 AA and follow GOV.UK accessibility guidance where it applies.

The site includes a skip link, visible keyboard focus, a labeled theme switch, titled embedded presentations, responsive layouts and support for reduced motion. The theme follows your device preference by default and can be changed from the navigation bar.

## Known limitations

I have not completed a full WCAG 2.2 AA audit or tested the site with a screen reader, so I cannot confirm that every page meets the standard. Quarto search, project filters and content inside embedded presentations have not been independently assessed with assistive technology.

## Tell me about an accessibility problem

If you have trouble using this site, email [James Tripp](mailto:James.Tripp@outlook.com). Please include the page you were using and what went wrong. You can also tell me which device, browser or assistive technology you use, if you are comfortable sharing that.
