# Backfillz

Software

Backfillz.R provides new visual diagnostics for understanding MCMC (Markov Chain Monte Carlo) analyses and outputs.

Author

James Tripp, Gregory McInerny

Published

May 4, 2020

[Code on GitHub](https://github.com/WarwickCIM/backfillz)

This software provides several novel visualisations for exploring MCMC chains. I worked with MCMC chains during the my post-doc in Psychology when estimating the posterior distributions of cognitive models given the data and found this project very interesting.
